# Autonomous Mapping Rover for Search and Rescue

## Overview

My final year Software & Electronic Engineering project focused on developing an autonomous rover to assist search and rescue operations in partially collapsed or rubble-filled buildings.

The rover aims to navigate an environment, detect obstacles and generate a 2D map of the explored areas to help resuce personnel access accessible spaces.

## Technologies

- ESP32
- Embedded C/C++
- Python
- React
- Git and GitHub
- AWS
